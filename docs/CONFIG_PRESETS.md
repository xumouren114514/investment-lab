# 保存与恢复研究配置

在“策略研究”顶部的“我的配置”中填写名称，点击“保存当前配置”。以后从“已保存的配置”选择并点击“载入配置”，即可修改后再次运行。同名保存会先询问是否覆盖；平时修改表单只更新草稿，不覆盖命名配置。

每次输入或选择后自动保存草稿，提交失败、刷新或关闭后重新打开都会恢复。保存包括快照ID及选择顺序、交易标的、日期、策略文件名、单次/滚动/留出设置、资金、杠杆、价格模式、费用、基准及三处JSON原文。尚未写完的JSON也能保存；运行时仍执行原校验。搜索词及结果面板不属于配置。

配置保存在当前浏览器的本机存储中，同一浏览器访问同一地址可恢复，页面代码更新不清除它。桌面应用、Codex内置浏览器和其他浏览器的存储各自独立；更换域名或端口也不会共享。清理浏览器数据会删除这些配置，平台数据目录备份不包含浏览器存储。

“导出 JSON”可下载文件，或复制弹窗中的全文自行保存。“导入 JSON”支持选择文件或粘贴全文，再点击“载入 JSON”；导入后可命名保存。文件只包含配置，不包含行情、Python源文件或研究结果；在其他环境使用前须准备对应数据和策略。单份文件上限1MB。

恢复后不自动改成新版快照。若原ID不在当前快照列表，界面保留编号并阻止提交；需检查数据或主动取消、重选。这不等于原归档已删除。缺失的Python策略、标的和基准同样明确标记。存储禁用、容量不足或文件损坏会提示，不显示虚假的保存成功；仍可通过JSON弹窗备份当前输入。
