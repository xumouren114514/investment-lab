# 账本与成交口径

## 上交所科创板订单数量

科创板股票按整股申报，买入最低 200 股，超过最低数量后按 1 股递增；不足 200 股的剩余持仓须一次性卖出。引擎按 1 股取整并校验申报订单，现金不足以买入 200 股时不成交，不会替策略向上加量。合法订单可因成交量参与率而部分成交，每次成交不足 200 股也可记账。低于 200 股的卖单仅在申报数量等于当时全部剩余持仓时允许；这笔有效订单也可因成交量限制分批成交。

旧行情快照中的“科创板买入最低数量和增量规则待实现”标记只在证券身份同时匹配 CN、XSHG、stock、六位688代码及原 `universe_id` 时被此规则接替；其他执行拦截、挂牌边界、公司行动和价格质量检查继续生效。新下载快照也保存整股增量及买卖最低数量。不因此推定成交、公司行动或严格VWAP已验证。交易所申报规则见[上交所2026年修订交易规则第6.7条](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)；1股递增和小于200股余数一次性卖出的示例见[上交所投资者教育说明](https://edu.sse.com.cn/tib/qa/c/4866268.shtml)。

## 同次回测使用多个数据快照（0.2.3 / Engine 5）

“数据快照”现在是支持搜索的勾选列表。多选表示在同一账户、同一初始资金和同一组研究参数下使用这些数据，生成一个运行结果；不是为每份数据另开一笔初始资金。新增快照中的非指数标的默认选入“交易标的”，可继续调整；指数需明确选择且只用于信号。策略仍决定实际买卖，并不会因为多选而自动分配仓位。

网页和CLI运行请求支持 `snapshots: ["快照ID1", "快照ID2"]`，旧 `snapshot` 单选请求继续可用。后台创建一个内容寻址的组合清单，直接引用原有证券/年度行情分区，不改价、不拷贝或覆盖原行情、不移动来源的当前指针。组合只在运行中引用，不增加“数据快照”选择列表中的来源条目。原始快照ID和名称保存在请求 `snapshots` / `data_sources` 及组合 `composition.parents`，结果详情可展开查看。

组合必须为同一市场、币种和时区，不允许合成/真实混合。同一标的重复来源按证券ID及已登记的 `universe_id` 检查；即使报价相同，也要求只选一份来源，避免无提示地决定供应商优先级。Yahoo参考价格与其他供应商不能混合，全部为Yahoo时继续采用原参考模式及逐行口径检查；严格VWAP、公司行动和其他执行守卫保持生效。

运行日期必须位于所有所选来源覆盖范围的交集内，页面添加快照时会把超出范围的日期调整到共同范围。组合交易日历取并集，保留预热历史和公司行动，缺失行情仍明确报错；不会通过交易日历交集悄悄跳过缺口。单次、滚动、留出和基准均使用同一个冻结组合，来源更新不会改变既有运行。

## 参考历史价格研究（0.2.1 / Engine 3）

用户已授权在缺少实际交易价格时使用参考历史数据。`reference_research` 支持本项目已识别的 Yahoo 股票/ETF 参考快照；界面选择此类数据时自动选中该模式并显示说明，API 的默认值仍是严格 VWAP。旧失败记录可按原参数另建参考运行，旧记录与行情快照保持不变。

参考模式的信号默认读 close，订单数量在决策时确定，下一交易日按参考 close 加滑点成交。已做拆股调整的序列不再次应用拆股，也不计现金分红，输出为不含股息的价格收益研究。数量按1个调整后参考份额取整，不宣称是历史实际股数或港股每手数；配置参与率只对供应商参考成交量作假设性限制。融资、费用和现金流仍使用配置，不宣称真实市场交易制度。

参考模式允许挂牌及公司行动未认证，但仅在快照的已有日历内运行，缺行情、晚到数据、未知/混合价格口径、跨市场币种、反向产品及其他执行限制仍阻止。完整期货参数不得通过此模式绕过。公司行动列表只在本次计算忽略，不修改归档数据。

所有单次、滚动、留出及基准结果保留 `reference_only=true`、`normal_ranking_eligible=false`、`point_in_time_prices_verified=false` 和具体假设。事后调整因子可能包含未来公司行动信息；按日期截断策略数据并不能把这一参考序列变成严格时点数据。因此参考模式的留出结果也不声称是严格时点有效的样本外验证。

口径核对：使用 Yahoo quote.close，没有改为 adjclose。拆股调整与未复权价格的差别见 [yfinance维护者说明](https://github.com/ranaroussi/yfinance/discussions/1682)；[Yahoo 对 adjusted close 的说明](https://help.yahoo.com/kb/SLN28256.html)另包含股息调整。本模式没有添加这类股息调整。以下原成交规则继续适用于严格/普通研究模式。

## 时间顺序

每个交易日先按上一交易日到当前日的实际日历天数计息，再处理现金流/到期资金及公司行动，执行上一有效决策日的订单，最后用未复权收盘价估值（期货用结算价）。策略在该日数据可用后回调；目前支持的数据可用时间必须早于当地 23:59:59，晚到数据会明确阻止，未冒充支持任意执行日偏移。

数量单直接冻结数量。金额单、目标权重单使用决策时最近已知收盘价换算，期货额外除以乘数；按交易单位向下取整。未来 VWAP 只在执行时用于成交、费用和现金/保证金约束。跳空导致资金不足时缩小成交量；不倒过来修改已冻结的原始订单。多个订单按提交顺序处理，强制减仓优先。

VWAP 是全日模拟基准，加入方向性滑点，不保证真实订单可成交。参与率对同标的同日订单合计限量。订单在市场交易日累计有效期，部分成交和到期剩余量入账。不能提交盘中时间/限价单，避免无依据使用全日 VWAP。遇停牌、零成交量或日线触及适用涨跌停，采用保守不成交。

策略 history 默认读取 VWAP；显式 close_research 或 reference_research 模式下默认读 close。读取其他字段可明确指定。内部历史视图为只读，避免每个交易日重复复制全部已知行情；`ctx.bars()` 仍返回策略可自行修改的字典副本。普通模式原始历史未做自动复权；跨拆股指标需要策略明确处理可知的调整事件。普通成交和账户按公司行动事件处理，不能使用 adjusted_close 再额外收一次股息。

## 资金与融资

### 每月入金简写（0.2.2 / Engine 4）

界面的“入金 / 提款”或配置 `cash_flows` 可填写 `{"monthly":3000}`。每月在本次回测区间内的首个交易日入金3000；首月即使从月中开始，也会在区间内首个交易日完整入金。日期依据已冻结的快照日历，休市日自然跳过，不向回测区间外补入金。金额采用该数据集的币种，不自动换汇。

可与单独日期合并，例如 `{"monthly":3000,"2024-02-01":500}`；若该日也是月度入金日，则合计3500。单独日期仍须为区间内实际交易日，正数入金、负数提款，不自动顺延。`monthly` 必须为大于0、最多两位小数的金额；删除该字段即可停用，`{}` 表示无外部资金流。页面示例按钮保留已填写的日期金额，将 monthly 设为3000。

入金沿用账户规则，先处理借款偿还，再增加可用现金；不自动下买单，也不计入投资利润。定期投入策略的 `amount` 是买入金额，与这里的入金金额分别设置，交易时序继续遵循下一交易日成交规则。

滚动窗口按各自实际起止日期重新生成月度入金；原有单独日期资金流仍按相对交易日偏移平移。开发区间和留出区间为独立账户，各自首月均入金，隔离区间不入金；基准使用与对应策略区间相同的资金流。原始简写保存在归档请求和 `metadata.cash_flow_schedule`，展开后的日期及同日合计保存在 `metadata.cash_flows`，结果页可展开查看。

金额 Decimal 运算、分到分币 HALF_UP；中间价格保留 Decimal 精度，交易数量整数/交易单位向下。现金与借款分别记账，有现金流入时先偿债；默认利息按实际日历日/365、按日历利率曲线积分、在下一交易日入账。不是简单把收益乘以杠杆。

股票价值 + 现金 + 应收分红 + 未结算卖出款 − 借款 = 权益。股息先在除息日记应收，支付日转现金；拆股同时改变股数和账面成本，不改原始行情。尚无可验证对价的碎股现金转换和配股会拒绝导入/处理。

默认零等待现金结算、股票单位来自证券配置（CN 可配置 sell_delay=1）。这些均是明确研究假设。规则可按 effective / market / symbol 改变佣金、最低佣金、卖出税、lot、sell_delay、cash_settlement_days。缺少真实历史参数时不能解释为实际市场制度。

新增融资受 max_leverage 和证券 margin_eligible 约束。维持权益比例不足后取消未完成订单，下个交易日强制平多；无法识别日内路径，跳空可能留下负权益，系统停止扩大头寸并保留损失。利率可使用 annual_interest 或 rate_curve；初始借款持有和每天目标杠杆再平衡为不同策略。

## 期货实验模块

支持用户导入真实月份合约模型：multiplier、tick、expiry、initial_margin、maintenance_margin 必须完整。买入不扣全额名义本金，冻结保证金可用量、收手续费，按结算价逐日盯市，平多实现价差，到期按结算价现金交割。tick 按对交易者不利方向取整。

预先固定日期的换月策略使用真实合约 ID 下单，不看未来成交量。**账本执行仍仅在合成样本验证**；0.2.0 另已接入中金所 2024-09 的 20 个真实月份合约、304 条日线作为数据评估，缺少历史参数时明确禁止执行。尚未接入三地完整月份链、夜盘交易日、历史保证金和交割费用。不能宣称完整 F 阶段已交付。正向杠杆 ETF 作为实际证券历史回测，不生成倍数假行情；真实产品接入仍待核实。

## 指标

外部现金流视为当天交易前入账；日收益为 E_t / (E_prev + Flow_t) − 1，链乘得到时间加权收益和回撤。净利润 = 末权益 − 初始本金 − 净入金。资金加权收益仅一年以上报告 XIRR，未找到单一根区间返回缺失。年化收益不足一年返回缺失；波动率和零无风险利率 Sharpe 用 252 交易日，Sharpe 至少 20 个观察值。胜率按已实现的卖出成交计，不等同于完整往返交易胜率。换手为绝对成交额/平均权益。

固定池存在事后选股偏差。滚动窗口重叠并不独立，不输出虚假的显著性。留出测试在本系统内首次/重复使用有记录；不声称外部从未看过数据。算法没有自动参数搜索或 walk-forward，不能把普通滚动起点误称样本外验证。
