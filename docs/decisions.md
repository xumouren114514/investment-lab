# 重要取舍

- D001 / 2026-09-20：使用 Python 3.12 + FastAPI + 原生网页，本机回环服务，无远程部署。符合单用户规模，减少前端依赖与维护上下文。
- D002：SQLite 仅为索引；immutable gzip JSON 为行情事实，按证券/年分区。优先正确性与可读性，性能不足再迁移 Parquet。
- D003：缺少供应商账号继续离线实现，以清楚标记的合成数据验收流程；公开 AAPL 仅证明 OHLCV 下载，不证明严格 VWAP 可用。
- D004：当前价格可用时间晚于当天决策窗口时拒绝。任意执行日偏移、盘中订单和订单类型扩展另立受测试变更，避免假支持。
- D005：备份清理只预览，不启用自动删除；先保留全部检查点并验证恢复。代码用本地 Git 身份标记自动化提交，不改全局身份，不推送。
- D006：只支持可核算的拆股/分红；未支持配股与碎股对价时拒绝。期货只声明实验账本验证，完整三地接入保留为未完成里程碑。
